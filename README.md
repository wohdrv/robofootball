# 🤖 Omni-Directional Robot for Robofootball

A fully functional omni-directional robot built on an **ESP32 platform** with independent wheel control and precise Bluetooth operation.

🎥 **Video Presentation:**  
https://youtu.be/iCxo-OgOEKI

---

## 🚀 Overview

This robot is designed for smooth, accurate movement in all directions using omni wheels and independent motor control.

The final system focuses on:

- High responsiveness  
- Stable wireless control  
- Accurate directional movement  
- Clean hardware architecture  
- Competition-ready mechanical platform  

---

## ⚙️ Hardware Architecture

### 🧠 Microcontroller
- **ESP32 WROOM (38-pin)**
- 38-pin expansion board

The ESP32 provides:
- High processing performance  
- Stable Bluetooth communication  
- Multiple PWM outputs for independent motor control  

### 🔌 Motor Drivers
- 2× ZK-5AD motor drivers

Each wheel is controlled independently, enabling:
- Forward / backward movement  
- Sideways movement  
- Rotation in place  
- Diagonal motion  

### 🛞 Drive System
- 4× Omni wheels  
- Independent control for each wheel  

The omni wheel configuration enables:
- 360° movement  
- Smooth transitions between directions  
- Precise positioning  
- No mechanical turning delay  

---

### 📱 Control System
- Bluetooth control via smartphone  

Bluetooth provides:
- Fast command execution  
- Minimal signal delay  
- High movement precision  
- Stable connection
